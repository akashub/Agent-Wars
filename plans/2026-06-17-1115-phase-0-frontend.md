# Phase 0 — Frontend (Guild Vault) Implementation Plan · Track B

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Build the full **Guild Vault** frontend — six screens (Boot → Create → Guild Hall → the Forge → War Contracts → Battle), navigable and matching `agent-wars-starter/reference/prototype.html`, running **mock-first** on seed data behind a single `lib/api.ts` seam, ready to flip to the live FastAPI backend with no screen changes.

**Architecture:** React + TypeScript + Vite SPA. CSS-custom-property design tokens with Tailwind mapped onto them (no CSS-in-JS). Zustand for client state. Shared types in `packages/contracts`. Scene state (not deep routing) drives a `<Viewport>`. All server access goes through one `lib/api.ts` module (`USE_MOCK` returns seed data + a simulated replay stream).

**Tech Stack:** Vite, React 18, TypeScript (strict), Tailwind, Zustand, Vitest + React Testing Library, ESLint/Prettier.

**Objective:** A clickable Guild Vault app: boot → create an Architect → Guild Hall → open the Forge and edit an Agent's six layers within a loadout budget → open War Contracts → deploy → watch a narrated Battle render from a seed replay → see a Verdict — all in the Guild Vault aesthetic, mock-first.

**Acceptance criteria:**
- `pnpm -C apps/web dev` boots the SPA; `pnpm -C apps/web test` and `pnpm -C apps/web lint` pass with zero warnings; TypeScript strict, no `any`.
- The full Boot→…→Battle flow is clickable and **visually matches the prototype** (diff against `agent-wars-starter/reference/prototype.html`).
- `prefers-reduced-motion` disables ambient/glint/spark; menus are keyboard-navigable with visible focus.
- Every scene gets its data through `lib/api.ts`; flipping `USE_MOCK` is the only change needed to go live later.
- **Vocabulary follows `agent-wars-starter/glossary.md`:** layer labels are **Persona, Tools, Memory, Strategy, Sub-agents, Model**; the entity is **Agent** (never "Champion"); world flavor (Guild Hall, Forge, Arena, Raid) is preserved.

**Sources of truth (DRY — do not re-derive):**
- Visual oracle: `agent-wars-starter/reference/prototype.html` (pixel-exact).
- Tokens + effects: `agent-wars-starter/design-system.md`. Components: `agent-wars-starter/component-library.md`. Screens + copy: `agent-wars-starter/screens-spec.md`. Types: `agent-wars-starter/data-model.md` (apply glossary rename). Seam: `agent-wars-starter/api-spec.md`. Structure: `agent-wars-starter/frontend-architecture.md`.
- This plan specifies **glue code and acceptance gates**; verbatim CSS/SVG/sprite-grids are **copied from the prototype/design-system**, not reinvented here.

// src/scenes/battle.reducer.ts
import type { ReplayEvent } from '../../../packages/contracts'
export interface BattleFx { side:'L'|'R'; callout?:string; sparks:number; hit:boolean; budgetDelta:number }
export function eventToFx(e: ReplayEvent): BattleFx {
  const sparks = e.hit ? 22 : e.type === 'tool_call' ? 10 : 5
  return { side: e.side, callout: e.callout, sparks, hit: !!e.hit, budgetDelta: e.budgetDelta ?? 0 }
}

```ts
// src/lib/api.ts (shape)
import { SEED } from '../../../packages/contracts/seed'
const USE_MOCK = import.meta.env.VITE_USE_MOCK !== 'false'
export async function getFocuses() { return USE_MOCK ? SEED.focuses : fetch('/api/focuses').then(r => r.json()) }
export async function* streamReplay(runId: string) {
  if (USE_MOCK) { for (const e of SEED.fallbackReplay) { await sleep(350); yield e } return }
  /* live: consume SSE from /api/runs/:id/stream */
}
// …one function per api-spec.md endpoint
```
