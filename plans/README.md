# Plans

Session plans for Agent Wars. One plan per working session (see the mandatory
workflow in `../CLAUDE.md`).

## Convention

Filename: `<YYYY-MM-DD>-<HHMM>-<objective-slug>.md`

Each plan begins with:

- **Objective** — the one outcome this session delivers.
- **Acceptance criteria** — measurable, checkable conditions for "done."
- **Steps / Tasks** — discrete tasks, each with its own test cases.

Progress and outcomes are captured in Eagle Mem and `../CHANGELOG.md`. A plan is the
contract for the session; if scope changes mid-session, update the plan.
